# Project Purpose

JobCodex is a job application tracker built with Next.js 14 and Tailwind CSS. It allows users to:
- Track job applications with details like company, program, work type, status, and notes
- View applications in two modes: Kanban board and List view
- Use drag-and-drop to change application status
- Filter applications by status and work type
- Search applications by company or program name
- Star important applications
- Delete applications (viewable in a separate deleted section)

The app stores data in `data/applications.json` and uses Next.js API routes for persistence.
