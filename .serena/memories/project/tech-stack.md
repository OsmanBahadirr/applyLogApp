# Tech Stack

- **Framework**: Next.js 14.2.30 (App Router)
- **UI Library**: React 18.3.1
- **Styling**: Tailwind CSS 3.4.17
- **TypeScript**: 5.x
- **Drag and Drop**: @dnd-kit/react 0.2.0
- **Theming**: Custom CSS variables with support for 4 themes (light, dark, mocha, frappe)
- **Icons**: Text/emoji-based (★, ☆, etc.)
- **Data Persistence**: File-based (data/applications.json) via Next.js API routes

## Dependencies
- @catppuccin/palette (for Catppuccin themes)
- @dnd-kit/react (drag and drop)
- next, react, react-dom (core)
